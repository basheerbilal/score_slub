# ⚽ Soccer Club Hub

A modern and responsive football club website built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite**. The project provides an engaging experience for football fans with a clean UI, smooth animations, and responsive layouts.

---

## 🚀 Features

- ⚽ Modern Football Club Landing Page
- 📱 Fully Responsive Design
- 🎨 Clean & Premium UI/UX
- 📰 Latest Club News Section
- 👥 Team Players Showcase
- 🏆 Match Fixtures & Results
- 📊 League Standings
- 🎫 Ticket Booking Section
- 📸 Club Gallery
- 📞 Contact Section
- ✨ Smooth Animations
- ⚡ Fast Performance with Vite

---

## 🛠️ Tech Stack

- React 18
- TypeScript
- Tailwind CSS
- Vite
- HTML5
- CSS3
- JavaScript (ES6+)

---

## 📂 Installation

Clone the repository:

```bash
git clone https://github.com/basheerbilal/score_slub.git
```

Go to the project directory:

```bash
cd score_slub
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
